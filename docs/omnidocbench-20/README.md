## 与旧20页的关系

旧 `docs/quality-corpus-20/` 及本地图片继续保留作业务补充材料。本子集提供现成真值，替代从零全文标注的工作。它目前是开发与评测集合，**不是已经核验的12/8严格留出划分**。上游部分文件只有不透明编号，完整源书身份不明；同名、哈希去重并不能证明不存在同书其他页面。源文档核验和冻结之前，不报告独立留出成绩。

## 标注与检查边界

## 来源与复现

[上游数据集](https://huggingface.co/datasets/opendatalab/OmniDocBench) · [官方评测代码](https://github.com/opendatalab/OmniDocBench)。

[manifest.json](manifest.json) 固定了版本、原始文件名、JSON索引及图像/标注SHA-256。下载时使用 `HF_ENDPOINT=https://hf-mirror.com`，通过 `uvx --from huggingface_hub hf download` 指定该revision、`--repo-type dataset`及清单列出的图片；仅下载所需图片与上游JSON/README，未下载全量图片。筛选记录原样保留于子集JSON，不能把图中试题的印刷答案当作解析模型应解出的答案。

已建立本项目文档输出到原始标注的几何匹配及正文/公式/表格/顺序、异常回退统计，见 [#17 评分口径](../issue-17/README.md)。20页分数只代表该子集，不是全量 OmniDocBench 榜单分数，也不是官方评测格式的适配成绩。
