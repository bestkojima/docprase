## 问题 3 金属阳离子被还原一定得到金属单质吗？


不一定,存在多种价态的金属可能从较高价态被还原到较低价态,但仍为化合态,如铁粉与氯化铁溶液的反应: $Fe+2Fe^{3+}=3Fe^{2+}$。

## 铁的氢氧化物比较


<table><tr><td>名称</td><td>氢氧化亚铁</td><td>氢氧化铁</td></tr><tr><td>化学式</td><td>$\mathrm{Fe(OH)}_{2}$</td><td>$\mathrm{Fe(OH)}_{3}$</td></tr><tr><td>颜色、状态</td><td>白色固体</td><td>红褐色固体</td></tr><tr><td>水溶性</td><td>不溶</td><td>不溶</td></tr><tr><td>与酸反应</td><td>$\mathrm{Fe(OH)}_{2} + 2\mathrm{H}^{+} = \mathrm{Fe}^{2+} + 2\mathrm{H}_{2}\mathrm{O}$</td><td>$\mathrm{Fe(OH)}_{3} + 3\mathrm{H}^{+} = \mathrm{Fe}^{3+} + 3\mathrm{H}_{2}\mathrm{O}$</td></tr><tr><td>稳定性</td><td>不稳定,在空气中会迅速由白色变为灰绿色,最后变为红褐色:$4\mathrm{Fe(OH)}_{2} + \mathrm{O}_{2} + 2\mathrm{H}_{2}\mathrm{O} = 4\mathrm{Fe(OH)}_{3}$</td><td>常温下稳定,加热分解$2\mathrm{Fe(OH)}_{3} \xlongequal{\Delta} \mathrm{Fe}_{2}\mathrm{O}_{3} + 3\mathrm{H}_{2}\mathrm{O}$</td></tr><tr><td>制备</td><td>$\mathrm{Fe}^{2+} + 2\mathrm{OH}^{-} = \mathrm{Fe(OH)}_{2} \downarrow$(必须在非氧化性环境中制备)</td><td>$\mathrm{Fe}^{3+} + 3\mathrm{OH}^{-} = \mathrm{Fe(OH)}_{3} \downarrow$</td></tr></table>

Fe(OH) $_{2}$ 为白色絮状沉淀, 在空气中迅速被氧化: 白色→灰绿色→红褐色, 此知识点常作为元素存在的检验方法和物质推断的重要突破口。
