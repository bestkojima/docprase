## 候选与真实运行

代码基点为 `88183cd0fb4acd3e72e78a40d7bc5140fefa8d7e`；本次新增评测工具和记录，生产推理代码未变化。模型及配置沿用现行 MNN CPU 单线程、SmartResize + Lanczos、版面阈值0.3、整页上限6400万像素、首次512 token、定向重试最多4096 token及默认120秒生成预算。冻结记录保存源码、二进制、实际加载的项目动态库、配置、模型和数据哈希。

模型大工件使用同文件系统硬链接，并在每个作业前后复核实际 SHA；这不是可抵抗原文件就地修改的独立副本。二进制、项目动态库、配置及门槛保存独立快照。初次复制因磁盘不足中止，随后软链接被生产路径校验拒绝；相关失败留档，未作为有效识别成绩。最终成绩来自修正后的新输出目录，全页重新执行，不复用历史识别结果。

主清单为 `docs/omnidocbench-20/manifest.json`，原图、原始标注及源版本不变；旧回归沿用 `docs/issue-15/samples.json` 的六份输入、七页。两个独立进程只用于缩短本次执行时间；各进程仍按单线程模型配置运行。墙钟和最大 RSS 属于每个进程在并行负载下的观测，不作为性能改善结论。采样运行时未配置随机种子，本次单次观测不构成识别结果逐字节必然复现的保证。

## 前后比较口径

修复前基线为 `docs/issue-17/report.json` 及其已提交原始 DocumentIR。固定20页全部保留，失败页也保留正文、行内/独立公式、表格、图片和顺序的完整参考分母。正文折叠 Unicode 空白后按总编辑距离／总参考字符数计算严格 CER；缺匹配、回退和整页失败用空串计删除。公式忽略空白及一次外层 `$$`；行内公式仍单独统计。表格整表要求结构、跨度和文字全部正确；单元格须同时匹配行列位置、跨度、header和文字。本次收紧了旧评分器只按数组下标核对单元格文字的口径，前后两侧均使用相同新口径，另保留原基线数值，不将评分变化称为识别改善。

版面覆盖匹配沿用 #17 的同类贪心一对一规则及0.5/0.8覆盖阈值，同一输出只匹配一个顶层参考块。逐页按相同标注 ID 列出新增漏匹配、原精确项丢失及恢复项；共同可评的同一标注对分别记录新增顺序错误和修正，不以总顺序分数抵消新增错误。严格 CER 的逐页增加也阻止工程通过。

一对一漏匹配可能由多GT/单Region粒度差异造成，尚未核验的项称为“漏匹配”，不冒称已确认漏内容；#26 的内容核验仍是工程验收条件。图片评分只表示定位和保存状态，不表示图片语义正确。旧7页只使用既有摘录、公式、表格、自制PDF十行及锚点参考，不虚构整页全文CER；原文诊断和严格可用内容分开报告。

正文raw转写CER作为补充诊断另列，包含非正常块，不能替代严格质量分数。标注争议保持上游原值作为主结果，ODB-15 的既有独立勘误另列；不凭候选输出改真值。raw重复启发式是疑点统计，不能当作确认错误。结构、漏块及重复归属未核验的条件继续阻止工程通过。

## 冻结质量门槛

`thresholds.json` 在本次识别及 #23 新材料正式识别前保存并由候选记录锁定。依据开发基线的已知短板设为后续验收目标，不按当前候选成绩降低，也不声称已经证明可达。

| 指标 | 必须满足 | 分母及失败计分 |
| --- | ---: | --- |
| 正文严格CER | ≤0.20 | 所有非ignore正文参考字符；缺匹配/回退按完整删除 |
| 行内公式精确率 | ≥0.80 | 全部嵌套行内公式；父块缺匹配或回退计错误 |
| 独立公式精确率 | ≥0.80 | 全部独立公式；缺匹配/回退计错误 |
| 整表精确率 | ≥0.80 | 全部表格；结构及文字均须精确 |
| 单元格精确率 | ≥0.90 | 全部参考单元格；位置/跨度/文字不符计错误 |
| 阅读顺序正确率 | ≥0.95 | 全部上游参考对；缺匹配对不计正确 |
| 回退比例 | ≤0.10 | 非正常状态的已匹配正文/独立公式/表格GT ÷ 全部这三类GT |
| 漏匹配比例 | ≤0.05 | 未匹配正文/独立公式/表格GT ÷ 全部这三类GT |
| 空间重复输出 | =0 | 正文/公式/表格/图片同类一对一匹配后的重复输出 |

使用全集微平均，全部指标同时满足才通过数值条件；全集某必需类别的分母为0记不可评，不能自动通过。逐页无该类别显示不适用，仍保留全集分母。行内公式不重复加入顶层回退/漏匹配分母。全部回退和全部漏匹配均不能通过。开发集数值通过也不能代替工程关及另一次带标注评测。

#23 最新修订已经取消来源身份、同卷同册隔离及开发曝光的准入条件，本次沿用“带标注评测集”术语，不重新加回这些已取消条件，也不声称材料已证明严格独立留出。最终质量验收尚未运行，后续 #25 使用已冻结门槛。
