# #31：模型转写与流水线逻辑的归因及修复

2026-10-03，用户要求确认历史困难页上的错误来自模型能力还是逻辑处理，并参照 Paddle 流水线处理。本轮范围是这些具体缺陷的归因和输入规划修复；不替代 #31 的全量八项质量验收。

## 对照实验

使用同一 Ovis 模型、贪心采样、生产提示词与 `adapt_visual` 路径，直接识别已保存裁图。正文对照只改变裁图上边界；公式对照只改变视觉像素预算。每个直接探针均预留 4096 token，不依赖截断后重试；原始响应与生产保存响应一致时才用于定位。原页重跑与单区域探针分别留档。

| 现象 | 证据 | 归因 |
| --- | --- | --- |
| 极值解析页把 `≤` 读成 `≥`，丢导数撇号并产生乱码 | 原裁图从上一行中部开始；仅把 y0 从 1769 改为 1753，相关文字和符号即恢复 | 裁图和部分重叠区域处理问题，不能直接归为模型能力不足 |
| 数列公式把 `2^{64}` 读成 `2^{54}` | 原完整裁图在 65536–313600 像素预算下复现；同图在 262144–1120000 预算下恢复 64 | 视觉细节预算不足；当前模型能够识别该内容 |
| 第19、21题重复且有互相冲突的副本 | 一个完整短行与另一段落的边缘部分重叠，两者各调一次模型 | 识别前内容归属问题 |
| 化学反应条件 `(ii)` 排在 `(i)` 前 | 右下角页码被用作右栏证据，跨页面中线的第一条件排到最后 | 阅读顺序逻辑问题 |
| 第18题第（1）问缺失 | 检测候选 c74 分数 0.268295，c79 为 0.232167，被 0.3 阈值拒绝；诊断阈值 0.2 下能识别问句 | 检测低置信度与召回筛选策略的共同影响；不是 Ovis 看不懂该问句 |
| 反应箭头、产物标记缺失 | 完整反应图候选 c28 分数 0.207052，被 0.3 阈值拒绝；0.2 下可保存完整图 | 检测/资源覆盖的召回问题 |
| 完整不等式正文漏绝对值起始符 | 输入未截断，原始响应已经输出 `$\lvert a+b\rvert<1+ab\rvert$` 对应的缺符表达式；高预算对照可恢复成对绝对值 | 模型转写对输入细节敏感，导出没有删符；不凭数学含义猜补 |

上述实验不能证明模型没有其他能力限制，也不能把“低预算错误”直接当作不可改善的能力上限。`ok` 和可排版只说明执行/结构检查通过，不证明符号与原图一致。

## Paddle 参照与本地适配

固定参照 PaddleX `ffb64904d23708863ff5b8da312a5cbd52a7f462`：

- [PaddleOCR-VL pipeline](https://github.com/PaddlePaddle/PaddleX/blob/ffb64904d23708863ff5b8da312a5cbd52a7f462/paddlex/inference/pipelines/paddleocr_vl/pipeline.py#L252)：区域筛选、裁图和块组合在 VLM 调用前完成，正文、表格、公式使用各自的视觉预算。此处借鉴职责划分；Ovis 继续沿用已验证的生产提示词与运行时。
- [PaddleOCR-VL utils](https://github.com/PaddlePaddle/PaddleX/blob/ffb64904d23708863ff5b8da312a5cbd52a7f462/paddlex/inference/pipelines/paddleocr_vl/uilts.py#L108)：按空间重叠过滤，另有块组合逻辑。原始候选的分数、框、mask、rank 仍是判断输入来源的依据。
- [LayoutParsingV2](https://github.com/PaddlePaddle/PaddleX/blob/ffb64904d23708863ff5b8da312a5cbd52a7f462/paddlex/inference/pipelines/layout_parsing/pipeline_v2.py#L317)：版面结构标准化与阅读顺序独立于后续显示格式化。

本地修复不宣称完整移植 Paddle 流水线：已有 text/formula/table 任务和 image 资源契约继续生效，未知/失败内容不改成 skip。

## 已实施规则

1. **部分重叠文字行的唯一归属。** 仅处理普通正文 class 22：短框宽高比至少 4、父段落高度至少短框的两倍、短框宽度为父框 0.6–1.1 倍，横向覆盖至少 90%、面积覆盖至少 40%，并跨过父段落顶部或底部。必须存在唯一父区域；多父候选保持原状。识别前取原框并集，短框记录 `overlapping_text_owned_by_text`，原 LayoutBlock、mask、分数和来源保留，仅执行父 text 一次识别。与被吸收行相关的公式也归最终父区域。相邻无重叠正文、跨栏正文、标题不适用，未启用一般相邻段落合并。
2. **页边内容不建立正文分栏。** 页码、页眉页脚、脚注和旁注不能仅凭左右位置制造第二栏，防止单栏里的跨中线短句排到末尾；已有双栏和图注顺序回归继续执行。
3. **独立公式的视觉预算。** 初次 formula 任务使用 262144–1120000 像素；text/table 保持既有预算。按识别前类型决定，不读取或猜测模型答案。实际变换和尝试配置仍记录在 provenance。重新导出同时接受旧公式预算和新公式预算，普通正文的初次高预算记录仍拒绝；不改封存 Schema。

没有将全局检测阈值改为 0.2：两张图的诊断改善不足以证明其对水印、装饰及其他难页的误检代价可接受。第18题漏行与完整反应图召回仍是待标定项，由 #31/#28/#29 的相关工作继续核验。没有全局提高正文预算，也没有在后处理中补写模型漏掉的符号。
