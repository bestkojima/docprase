## 表示、对齐和导出分别记录

- `representation`：空格、全半角标点、Markdown 标题、`℃/°C`、已逐符号核对的 LaTeX 写法等。这个标签没有豁免渲染错误或改变严格匹配要求。
- `transcription_error`：原图可确认的文字、数字、运算符误写或漏写。
- `coverage_error`：原图内容缺少机器可读转写。出版社标志、节号等可能仍在图像中，不能把缺可读文字说成整页视觉内容丢失。
- `structure_error`：表格错列、合并格丢失、重复填格等，与格中文字是否正确分别记录。
- `alignment`：GT 父段落和预测块的粒度不同；已选定的补充块放在 `evidence_blocks` 中。一个块可能同时含相邻题目，不能把它的全部文字都算作当前项目。
- `reference_issue`：原图与参考标注存在遗漏、误字或未收块。未修改 GT，也没有从原评分分母中删项。
- `export_fallback`：development-odb-11 的大表和 development-odb-17 的两张化学表最终均为 `table=null`、空文本、PNG 降级。化学表的原始内容可逐格确认，最终依然不是可编辑表格。
- `unverified`：证据不足，保留待核验。

原始算法 `strict_exact`、正文字符 `differences` 和行内公式诊断均保留。正文字符差异是在原评测规范化／配对跨度上定位，不能当作原始响应逐字符差异。`reviewed=true` 表示已有裁决，裁决可能是错误或缺失，**不表示内容正确**。最终内容、原始响应和块状态在证据中分别保存。
