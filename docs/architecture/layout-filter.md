# 版面候选筛选

第 4 项结构优化将 NMS、大图片、包含和外层重叠筛选集中到 `layout_filter` 模块。`page_pipeline` 将已通过张量契约和安全检查的候选一次交给 `filter_layout_candidates(width, height, candidates)`，取得完整筛选记录后继续执行候选复核与页面规划。

```mermaid
flowchart LR
    A[版面推理与张量解码] --> B[NMS 与大图片筛选]
    B --> C[包含筛选]
    C --> D[外层重叠筛选]
    D --> E[完整候选记录]
    E --> F[显式候选复核]
    F --> G[冻结页面计划]
    E --> H[导出诊断]
```

## 文件职责

| 文件 | 职责 |
|---|---|
| `src/layout_filter.hpp` | 只接收页面尺寸与候选记录的单一筛选入口 |
| `src/layout_filter.cpp` | 原有筛选流程的顺序、阈值、父子内容保护与筛除原因 |
| `src/layout_candidate.hpp` | 保存全部候选的原始几何、类别、rank、mask 来源及筛选结果 |
| `src/layout_geometry.hpp` | 筛选与页面规划共用的覆盖率和重叠文字行规则 |
| `src/layout_output.cpp` | 张量与 mask 契约验证、坐标回映、分数和几何安全检查 |
| `src/page_pipeline.cpp` | 组合候选筛选、复核、冻结计划、区域执行和文档导出，负责预算与资源提交 |
| `tests/layout_filter.cpp` | 通过同一入口直接验证完整流程的组合行为，不需要模型、像素或资源创建 |

## 入口约定

- 输入页面有效，选中候选已通过分数与几何检查，`crop` 已裁到页面；原始浮点 `box` 与裁剪框分别保存。
- 候选按值传入，调用方可以移动交接，结果按值返回。仅 `selected` 和 `reason` 改变，候选数量、存储顺序、身份和其他来源字段保留；未选中的记录继续保留原筛除原因。
- 顺序固定为 NMS、大图片筛选、包含筛选、外层重叠筛选。调用方不需要了解各内部步骤或决定执行顺序。
- 两个页面边长都至少为 6 像素时才执行包含与外层重叠筛选；小页仍执行 NMS 与大图片规则，保持旧 2×2 契约夹具行为。
- 包含筛选使用进入该步时的选中状态快照，以记录索引访问快照；候选编号不必与存储索引相同。
- 筛选不修改几何、不合并内容、不决定内容归属或阅读顺序，也不执行图片、mask 与模型操作。显式复核需要真实像素和张量，继续在调用方执行。

## 保持的数值与保护规则

NMS 使用原始页坐标的浮点框与 inclusive `+1` 面积，同类阈值 `>= 0.6`、跨类阈值 `>= 0.98`。优先保留高分框，同分时保留原记录中靠后的框，rank 不参与 NMS 优先级。类别 14 的大图片按页面内交集面积筛选：横页严格 `> 0.82`，其他页面严格 `> 0.93`；不删除唯一剩余候选或筛除全部大图片。

包含筛选使用浮点框及 `>= 0.9` 覆盖率，保留原类别集合 `{3,5,6,15,17}` 和类别 5 的方向保护。外层重叠筛选使用页面内整数裁剪框，交集/小框面积严格 `> 0.7` 时处理重复，并保持原记录的配对遍历次序。

表格子内容、行内公式、伸出段落边缘的文字行、小图注和脚注，以及不同特殊内容类别继续按既有规则保护，交给页面规划处理归属。原始筛除原因和候选追溯格式保持兼容。该拆分不表示已对齐完整官方后处理；历史策略差异见 [几何与归属记录](../issue-20/geometry-and-ownership.md)。

Release 无模型构建的 38 项 CTest 全部通过，包含新增筛选入口测试、去重与几何集成、候选复核、页面规划、PDF、取消和重试。本轮 `core.cpp` 从 1139 行减少到 982 行。
