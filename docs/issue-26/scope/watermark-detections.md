# 诊断水印及装饰误检并保护有效插图

Part of #16。承接 #26 原规格的水印/装饰误检处理，独立于横排选项及标签绑定验收。

## 问题与交付

真实整页 odb-03 中水印候选 c34 被保留为 image。此类检测误检与 NMS 重复框、图注错配和 OCR 转写错误不同。建立有真实原图/内容证据的误检诊断与处理策略，同时保护有效选项图、教材插图、页眉和短标签。

## 验收

- [ ] 保存 odb-03 已知误检及其他可确认水印/装饰反例；记录原图、候选、LayoutBlock/Region、类别、分数、rank、mask 与判断理由。
- [ ] 疑似误检保留原图与原因；不能凭尺寸、位置、颜色或重叠的单一规则删除有效内容，也不能凭缺少 GT 一项直接确认水印。
- [ ] 使用受控及真实正反例证明有效选项、有效插图、页眉和短标签不会被新规则误删；模糊情况不静默丢弃。
- [ ] 通过公共 CLI/C ABI 作业入口验证策略；区分检测误检、重复框、结构错误和转写错误，保存修复前后产物与版本来源。
- [ ] 若修改候选/裁图/归属，核验对应内容无新增确认的遗漏、重复或跨栏混合，并重跑 #26 的图文结构回归。

本任务不解决 OCR 错字、公式语法校验或全部正文识别精度；这些继续由 #21/#24/#27 跟踪。

## 后续标签处理约定（2026-10-01 用户要求）

Ovis 只有 **text / formula / table** 三种区域识别任务。DocLayout 的其他文字 label 先集中映射到三类，不为每个原始 label 添加识别任务或重复诊断。原始 class ID、label、框与处理原因仍可追溯。

- 标题、正文、图注、脚注、页眉页脚与编号等文字细类映射为 text；独立公式映射为 formula，整表映射为 table。
- 已确认属于正文的内嵌公式由父 text 一次输出；表格文字/公式子块由父 table 一次输出，不重复调用 Ovis。
- image/chart/seal 等图像保存为资源，类型字段为 image，跳过 Ovis，由 Markdown 引用保存的图片地址。image 是资源类型，不是第四种 Ovis 任务。
- 对明确无需处理的其他 label，可以适当添加显式 skip。写清适用标签及条件、保留跳过原因，并核验受影响的有效文字/插图；未知或不明确的标签不默认静默丢弃。
- 资源不识别、已归属子块不重复识别、label 显式 skip 分别记账，均不计作 Ovis 识别成功或失败。已执行但识别/校验失败的三类任务不能改为 skip 来改善成绩。

契约和当前/后续实现边界随 #26 提交于 `docs/issue-26/label-policy.md`；本票沿用统一映射，不重新要求 GT 框与识别任务一一对应。

本票可对确认的水印、装饰或无需输出的 label 实施明确 skip；有效选项图、教材插图继续作为 image 资源保存。新的 skip 策略在本票实现，#26 的1.9候选没有额外加入这类过滤。
