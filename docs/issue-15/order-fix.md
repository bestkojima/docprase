# 双栏分节阅读顺序修复记录

冻结输入 `printed_science_2col.png` 首轮真实模型作业保存在 `evidence/en_two_column/`。模型给出了页眉、两节标题、两栏正文和图的框，但 `reading_order_evidence.reason=model_column_conflict` 后的几何回退把 `b0001` 页眉、`b0002` 第一节标题排到正文之后，并把 `b0010` 第二节标题及页尾内容插入左栏正文后、右栏正文前。原始评分是已识别 15/16 锚点、72/105 可判定顺序对正确；图注 `b0008` 在 512 token 达上限，没有可靠文字。

通过公共 CLI fixture 入口新增 `printed_page_reading_sectioned`：宽但不足旧 65% 阈值的页眉、左页边短分节标题、两栏正文与后续分节标题。修复前测试退出非零，实际候选顺序为 `[1,2,4,6,9,11,3,5,7,8,0,10]`，日志见 `evidence/red-test.log`。修复后目标顺序为 `[0,1,2,4,6,3,5,7,8,9,10,11]`，定向测试通过。另有 `printed_page_reading_local_title` 反例：左栏局部小标题与右栏正文同高度时，保留左栏内部顺序，不切成全页新节；原有单栏、常规两栏和居中短跨栏标题仍在同一个公共测试中。

通用修复在 `src/core.cpp`：跨过页面中部的页眉成为分段边界；靠左页边的 `paragraph_title`/`doc_title` 只有在右栏上下至少一个标题高度的垂直空带内，才成为全页分节边界。它按类别、原页几何与当前页块判断，未改模型阈值、提示词、样本和冻结评分。原有五份输入逐页检查，没有任何块新增分段边界；它们的首轮真实模型结果保持原样，公共回归覆盖排序逻辑。
