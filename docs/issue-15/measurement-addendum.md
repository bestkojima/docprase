# 运行前测量说明补充

本文件在首轮真实运行前补充冻结规则，不变更质量比较。#6 已证明生产 stb 与 Pillow 对同一 JPEG 的解码可相差至多 1 个通道值。因此 PNG 坚持裁剪像素逐字节相同；JPEG 先检查裁剪尺寸，再以 Pillow 原图 RGB 作为独立参考，所有通道最大绝对差允许 `<=1`，实际最大差写入报告。此项只保证解码容差内的原图定位，不把 Pillow 像素当作生产 stb 的完全同一数组。

另在同轮公共 C ABI 连续作业中以 `time.monotonic()` 单独量 `dococr_create` 调用时长，报告为**引擎创建（配置/哈希/模型加载）**；它不包括 Python 启动、模块导入和读输入文件，也没有清理 OS 页缓存。CLI 的 `/usr/bin/time -v` 新进程整段另报外层墙钟，不称为模型加载时长；清单阶段耗时和两次同引擎作业时长另列。内存解释沿用 `rules.md`。
